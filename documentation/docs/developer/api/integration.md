The NPDA audit year opens on 1st April and ends on the 31st March. 

Once a Paediatric Diabetes Unit has a token with the correct permission ('read', 'write') they can begin sending requests. Any requests creating patients on or beyond the 1st of April will automatically create a new submission. This is flagged in the advisory message in the response headers.
